# HEART — Google's UX Measurement Framework

## Overview
HEART is Google's framework for measuring user experience at scale. It covers the full spectrum 
from emotional response to business impact. Best suited for consumer-facing products and 
commercial applications where engagement and retention matter.

## Dimensions

### 1. Happiness (Weight: 0.20)
How satisfied and delighted are users?
- Measure: Satisfaction surveys, NPS, sentiment analysis
- Rules should focus on: visual appeal, micro-interactions, delightful details, tone of voice, 
  emotional design at key moments (success states, onboarding, first-time use)

### 2. Engagement (Weight: 0.20)
How deeply do users interact with the product?
- Measure: Session duration, feature adoption, interaction depth
- Rules should focus on: compelling content, progressive disclosure, personalization, 
  gamification elements, social features, notification design

### 3. Adoption (Weight: 0.20)
Are new users successfully onboarding?
- Measure: Sign-up completion, first-value-moment rate, feature discovery
- Rules should focus on: onboarding flows, empty states, first-run experience, 
  progressive complexity, clear value proposition

### 4. Retention (Weight: 0.20)
Do users come back?
- Measure: DAU/MAU, churn rate, return visit frequency
- Rules should focus on: habit loops, saved state, re-engagement hooks, 
  notification strategy, content freshness

### 5. Task Success (Weight: 0.20)
Can users accomplish what they came to do?
- Measure: Task completion rate, error rate, time to complete
- Rules should focus on: clear CTAs, intuitive navigation, helpful error messages, 
  search quality, form usability

## When to Use
- Consumer-facing apps and websites
- E-commerce platforms
- Content and media platforms
- Social applications
- Any product where growth metrics matter
- Subscription-based products

## Scoring
Each dimension scored 0–100. Equal weight by default, but can be adjusted based on 
product stage (e.g., early-stage products may weight Adoption higher).
- 90–100: Exceptional experience
- 70–89: Good experience with room for optimization
- 50–69: Functional but users aren't thrilled
- Below 50: Significant experience problems affecting business metrics
